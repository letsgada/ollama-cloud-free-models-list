# Ollama Cloud Free Models List

To the frsturation of the [community](https://www.reddit.com/r/ollama/comments/1ss2spe/ollama_cloud_free_suddenly_no_longer_works_with/), some Ollama Cloud models
are no longer available for the free-tier.

This Repo uses github action to check Ollama Cloud Models once a day to see which one is available on free tier.

The list of model is updated daily at [models.json](https://letsgada.github.io/ollama-cloud-free-models-list/models.json)
